# 기존 프로그램(컴시간) 분석 메모

새 프로그램 설계를 위해 컴시간 제품군의 매뉴얼과 설치 파일을 분석한 결과입니다.
기능 구성을 파악하는 용도로만 사용했고 코드는 재사용하지 않았습니다.

## 제품 구성

| 프로그램 | 본체 | 역할 |
|---|---|---|
| 주간시간표 | ju_hour2.exe | 학기 기초시간표 작성 (자동 배정) |
| 일과진행 | ilgwa_n2.exe | 날짜별 결보강·수업교환·변경 시간표 운영 |
| 컴시간알리미 | alrimi2.exe | 교사용: 시간표 열람, 수업교환 요청·결재, 특별실 예약, 공지·쪽지·자료집계 등 |
| 감독교사 | gamdog2.exe | 정기고사 감독 배정 (정·부·복도·학부모 감독, 누적 횟수 균형) |

- 모두 Visual Basic 6 (MSFlexGrid, Winsock, Jet DB). 학교 PC의 '일과서버'를 통해 통신.
- 데이터 흐름: 교사별 시수표(엑셀) → 주간시간표 → 일과진행 → 알리미 / NEIS 일괄파일

## 좋았던 점 (유지)

- 연쇄 이동 미리보기, 이동 전 문제점 표시
- 작업 기록 자동 저장·시점 복원
- 미배정 목록 중심의 수동 배정
- 변경 교시 색 표시
- 교사별 시수표 엑셀 한 번으로 기초자료 입력

## 비효율 (개선 대상)

1. 순서 강제: 요일별 시수·시수표를 고치면 매번 [시간표 작성하기]로 재준비, 시수표 재가져오기 시 전체 초기화
   → **변경 즉시 반영, 자동 점검**
2. 연속/동시/특별실/일괄/복수교사 등록부가 따로, 조합 규칙 암기 필요
   → **수업(Lesson) 하나 + 동시 그룹으로 통일**
3. [자동 조정하여라] 반복 클릭
   → **CP-SAT 한 번 실행, 불가능하면 충돌 조건 설명**
4. 엄격한 엑셀 양식(셀 병합, 순번, 약칭 2자)
   → **머리글 자동 인식, 중복 줄 합산, 약칭 제한 없음**
5. 프로그램 간 기초자료 이중 관리
   → **하나의 프로젝트 데이터** (일과·감독은 같은 데이터 위에 확장 예정)
6. 서버 PC 의존, USB로 폴더 복사해 이전
   → **웹 서버 + JSON 백업/복원**
7. NEIS 과목·교사명 불일치를 업로드 단계에서야 발견 → (예정) 입력 단계에서 대조

## 단계별 계획

1. (현재) 기초시간표 작성: 기초자료, 자동 생성, 수동 수정, 엑셀 내보내기
2. 일과 운영: 날짜 등록, 결보강·수업교환(최소 변경 재계산), 변경 시간표, 시수 누계
3. 교사용 화면: 내 시간표, 교환 요청·결재, 특별실 예약
4. 정기고사 감독 배정
5. NEIS 일괄파일, 한글(HWP) 출력
