# 시간표 도우미

학교 수업 시간표를 만들고 고치는 웹 프로그램입니다.
기초자료(교사·학급·과목·시수)를 넣으면 제약 최적화 엔진(Google OR-Tools CP-SAT)이
필수 조건을 모두 지키는 시간표를 자동으로 만들고, 화면에서 칸을 눌러 옮기거나 맞교환할 수 있습니다.

## 실행

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

브라우저에서 `http://localhost:8000` 을 열고 **[예제 학교로 체험하기]** 를 누르면 바로 둘러볼 수 있습니다.
자료는 `data/` 폴더(환경변수 `TIMETABLE_DATA` 로 변경 가능)에 JSON 으로 저장되며, 저장할 때마다 이전 상태가 백업됩니다.

## 작업 순서

1. **기본 설정**: 학교명, 수업 요일, 학년별 요일별 교시 수, 일과 시간, 품질 기준
2. **교사**: 이름, 배정금지 시간(칸을 눌러 설정), 하루 최대 수업
3. **학급**: 학년별 학급 한 번에 만들기, 담임
4. **과목·특별실**
5. **수업(시수표)**: 한 줄 = 한 수업. 컴시간 형식의 *교사별 시수표 엑셀*을 그대로 가져올 수 있습니다.
6. **자료 점검**: 고칠 때마다 자동 점검 (학급 시수 합계, 교사 가용 시간, 특별실 용량, 동시 그룹 구조 등)
7. **자동 생성**: 불가능하면 서로 충돌하는 조건을 알려 줌
8. **시간표 보기·수정**: 학급별/교사별/전체. 칸 선택 → 옮길 칸 클릭(초록=이동, 주황=맞교환, 흐림=불가).
   🔒 고정 후 [나머지 자동 정리]로 고정 칸은 두고 나머지만 다시 배정. Ctrl+Z 되돌리기.
9. **내보내기**: 엑셀(전체·학급별·교사별), JSON 백업, 이전 저장본으로 되돌리기

## 수업 하나로 모든 경우 표현

| 상황 | 입력 방법 |
|---|---|
| 일반 수업 | 학급 1개 + 교사 1명 |
| 합반 | 학급 여러 개 + 교사 1명 |
| 복수교사(코티칭) | 학급 1개 + 교사 여러 명 |
| 연속수업 | 연속 칸에 `2` (2시간 연속 1회), `2,2` (2시간 연속 2회) |
| 특별실 | 특별실 선택 (같은 특별실은 동시에 한 수업) |
| 수준별 이동수업·선택과목 | 수업 여러 개에 같은 **동시 그룹** 이름 (학급이 겹쳐도 분반으로 처리) |
| 창체 등 학년 일괄 배정 | 학급별 창체 수업에 같은 동시 그룹 이름 |
| 이동금지 | 시간표에서 🔒 고정 |
| 배정금지 | 교사 화면에서 칸 선택 |

## 구조

```
app/
  model.py      데이터 모델 (Project, Lesson 등)
  checker.py    기초자료 점검 / 시간표 점검 (솔버와 독립)
  solver.py     CP-SAT 모델, 품질 목적함수, 충돌 원인 진단
  excel_io.py   교사별 시수표 가져오기, 시간표 엑셀 내보내기
  storage.py    JSON 저장소 + 자동 백업
  sample.py     예제 학교
  main.py       FastAPI (REST API + 정적 화면)
  static/       화면 (빌드 도구 없는 순수 JS)
tests/
docs/analysis.md  기존 프로그램(컴시간) 분석 메모
```
